Private · verifiable · AI router

Private AI
you can verify.

The trust gap: on a typical AI service the app, the cloud and the model host can all read your prompt. You only have their word.

deRoute swaps their word for proof. Your browser hides your personal details, verifies the sealed hardware, and locks each message so only that hardware can open it. Not us, not Google, not MongoDB.

Plate 05 · Why it wins drouter-demo.vercel.app
Why it matters

Frontier AI for work that must not leak

Clinical notes, contracts and code with live keys can use frontier models, with no one in between to trust.

Track · Google DeepMind Gemini 4 Argon

Gemini plans. It never reads.

  • Content-free control plane. gemini-4-argon gets a task outline: kind, $INPUT handle, token bucket, coarse counts, check flags. Never words.
  • Closed-schema gate on every Google-bound message: exact keys, handle grammars, power-of-two buckets; at most 66.89 bits per request.
  • Official @google/genai Interactions API, store: false, 5 tools over opaque handles, at most 5 steps.
  • Egress receipts. Each request’s sha256 joins the RFC 6962 log, with a signed tree head and inclusion proof.
LIVE/api/gemini/plan returns a gemini-4-argon plan plus its egress receipt. If Google fails, it answers 503, never a simulated plan.
Track · MongoDB Atlas

Atlas searches. It never learns your lookups.

  • Native $rankFusion of $vectorSearch (768-dimension cosine index) and $search (Lucene text index) on Atlas 8.0.
  • Attested embeddings from Tinfoil’s nomic-embed-text enclave. Public queries are filtered in the browser and again on the server.
  • Whole-library retrieval. Private runs fetch all 16 documents as one identical file and rank locally. Query parameters get HTTP 400.
  • Zero-PII collections: no prompts, no IP addresses, timestamps coarsened to the hour.
LIVE/api/atlas reports Atlas $vectorSearch + Atlas $search, fused by $rankFusion, 768 dimensions.
