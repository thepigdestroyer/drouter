dRouter: confidential AI routing

Clinical researchers, lawyers, and security teams need frontier models without exposing prompts to the AI provider, the host, or us. Before a prompt leaves the browser, dRouter verifies a signed hardware report: an AMD SEV-SNP router enclave (`router-0.tinfoil.sh`) and an Intel TDX model enclave with NVIDIA confidential-computing GPUs, matched to a signed Sigstore release. It scrubs personal details, normalizes style, pads the message to a 4,096-byte power-of-two bucket, and encrypts it with RFC 9180 HPKE so only that enclave can read it. It works in the browser, an OpenAI-compatible API, and a CLI, with unlinkable 2048-bit RSA blind-signed credits, a BIP39 passphrase vault, and `node-seal` CKKS homomorphic classification. A Gemini 4 Argon agent runs verification as an Interactions API tool-calling loop, anchored on Circle Arc testnet after human approval. MongoDB Atlas 8.0 searches provider intelligence and coarsened receipts via native `$rankFusion` (`$vectorSearch` + `$search`).
