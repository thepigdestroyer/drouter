dRouter: confidential AI routing

Clinical researchers, lawyers, and security teams want frontier models without exposing prompts to the AI provider, the host, or us. Before a prompt leaves the browser, dRouter checks a signed hardware report: an AMD SEV-SNP router enclave and an Intel TDX model enclave with NVIDIA confidential-computing GPUs, matched to a signed open-source Sigstore release. It scrubs personal details, pads the message to a fixed size, and encrypts it so only that enclave can read it. Relay and host see only same-size ciphertext. It works in the browser, an OpenAI-compatible API, and a CLI. A Gemini 4 Argon agent runs verification as an Interactions API tool-calling loop. Code computes the pass/fail gates, Google receives only scrubbed text, and a human approves before a run is anchored on Circle Arc testnet. MongoDB Atlas searches provider knowledge, hardware advisories, and past receipts with $vectorSearch and $search fused by $rankFusion.
