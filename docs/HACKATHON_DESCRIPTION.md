deRoute: split-knowledge private AI routing

deRoute lets a fictional hospital data scientist review clinical trial code and notes with frontier AI models without exposing personal details or secrets to Google, MongoDB, the host, or us. On the device, a deterministic filter (fingerprint anchored on Circle Arc Testnet, tx 0x09055dc1b5d6a79de9d96824ee76213b2c238a8bfd744ab143405d30db1fe730) and a Tinfoil pii-filter enclave scrub identifiers before sealing prompts with RFC 9180 HPKE to 6 attested Tinfoil enclaves (AMD SEV-SNP router, Intel TDX, and NVIDIA Confidential Computing GPUs).

For the Google DeepMind Gemini 4 Argon track, Gemini 4 Argon plans via the @google/genai Interactions API as a content-free control plane behind a closed-schema egress gate (56.35 bits max per TaskDescriptor, 66.89 bits per request) with signed egress receipts. For the MongoDB Atlas track, private runs download the 16-document corpus for local BM25 ranking, while public search runs native MongoDB 8.0 $rankFusion ($vectorSearch plus $search) on 768-dimensional embeddings.
