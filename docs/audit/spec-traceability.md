## 3. v1 Items Still Open (Prioritized)

1. **P0 - GPU Custody Module & CPU Plaintext Exposure (v1 D3, G3, S3, §2.4)**:
   - *Gap*: All custody crypto (`src/lib/custody/`) is simulated in TypeScript on the CPU, and live Tinfoil enclaves terminate HPKE on the CPU and run a router safeguards classifier sidecar (`gpt-oss-safeguard-120b` + `kimi-k3`) and usage reporter.
   - *To close*: Implement the CUDA custody module on dedicated 8x H200/B200 CC bare-metal nodes without router inspection sidecars.
2. **P0 - Multi-Operator Separation of Duties & Live Verifier Quorum (v1 G6, S7, §4, §5, v2 M1)**:
   - *Gap*: Verifier, builder, reviewer, and regional checker signatures (`src/lib/transparency/`, `src/lib/threshold/shamir.ts`) are derived from deterministic seeds inside a single Next.js app.
   - *To close*: Deploy independent verifier nodes in separate jurisdictions holding distinct hardware-backed Ed25519 keys, and enforce $k$-of-$n$ verification on the Arc smart contract.
3. **P1 - Physically Separate Oblivious Relay Operator (v1 G5, §6, v2 M4)**:
   - *Gap*: `/api/relay` runs inside the same Next.js deployment as the web UI, so the application host observes both client IPs and relay timing.
   - *To close*: Host the Oblivious Relay on an independent operator domain and route browser traffic through RFC 9458 binary OHTTP (`src/lib/ohttp/rfc9458.ts`) to the target gateway.
4. **P1 - Real Attested MicroVM Tool Sandbox (v2 M6)**:
   - *Gap*: `src/lib/sandbox/microvm.ts` simulates Python/Bash execution with regexes in TypeScript.
   - *To close*: Wire tool calls to a real ephemeral Firecracker/Kata confidential VM or Vercel Sandbox with attested session-key binding.
5. **P1 - Kimi K3 1M Context Window & Tier A Model Enclave Host (v1 G1, G2, §2.1)**:
   - *Gap*: Live Tinfoil Kimi K3 runs on Intel TDX (Tier B CPU) with `max-model-len` 262,144 tokens instead of AMD SEV-SNP (Tier A) at 1M tokens.
   - *To close*: Provision an 8x B200 node on AMD EPYC Turin SEV-SNP with 1M context enabled and run PT1-PT5 benchmarks.
6. **P2 - On-Chain Collateral Staking, Heartbeats, and Slashing on Arc (v1 §4, §8)**:
   - *Gap*: The Arc testnet registry (`0xbc8085c2b6fe6e0db05f169925c0b841828f4481`) tracks metadata and receipt anchors, but does not lock ERC-20 USDC or execute automatic slashing on canary/bounty proofs.
   - *To close*: Extend the Solidity contract with USDC vault bonding, 72-hour dispute windows, and on-chain P-384/Ed25519 proof verification.
7. **P2 - Committed Model BPE Tokenizer & Hour-Coarsened Logs (v1 §1, v2 §1.3)**:
   - *Gap*: Client token counting uses `byteLength / 4`, and timestamps in `credits/ledger.ts` and `forensics/bundle.ts` use millisecond `Date.now()`.
   - *To close*: Bundle the committed tiktoken/sentencepiece vocabulary on the client and truncate persisted billing/audit timestamps to `YYYY-MM-DDTHH:00:00Z`.
